I work on open-source graphics drivers and on bringing up Linux and Android
on MediaTek and Qualcomm devices. Most of my work starts with undocumented
hardware or proprietary binaries and ends with a patch, a device tree or a
written analysis. I mainly write C and Python.

### Work

- 🎮 **Mesa** — Panfrost / PanVK support for Mali Valhall (G615); upstream fixes merged
  in PanVK, Gallium and piglit. Currently writing a `mali_kbase` backend so PanVK can run
  on stock vendor kernels
- 🐧 **Linux & Android bring-up** — mainline device trees for Qualcomm MSM89xx / SDM4xx phones, plus
  TWRP and LineageOS trees for Xiaomi MT6897 / MT6899 ([degas](https://github.com/Advnirr/twrp_device_xiaomi_degas), [chagall](https://github.com/Advnirr/twrp_device_xiaomi_chagall))
- 🛠️ **Tools** — [lufux](https://github.com/Advnirr/lufux) (bootable USB / Windows To Go on Linux),
  [hanuchi](https://github.com/Advnirr/hanuchi) (GTK4 frontend for Hamachi)
